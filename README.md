# React-Recipe-App
## Requierements
- Node.js
- pnpm
## Initialisierung des Projekts
WICHTIG: nur nötig wenn das Projekt frisch geklont wurde. Darauf achten das man sich in /prototype befindet. npm auf keinen fall benutzen.

```
pnpm install
```
## Wie das Projekt gestartet wird
einfach eingeben
```
pnpm dev
```
